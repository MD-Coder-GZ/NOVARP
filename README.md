# NOVA RP — правила проекта

Новая главная страница — index.html. Старый rules.html перенаправляет на неё.

## Файлы
- index.html — интерфейс.
- style.css — адаптивное оформление и темы.
- rules-parser.js — разбор и очистка полного исходника.
- search.js — загрузка правил, навигация, поиск, подсветка и ссылки.
- Текстовый документ.txt — полный исходник правил; имя файла нужно сохранить.

Сайт работает на статическом HTTP(S)-хостинге, включая GitHub Pages. Сервер приложений, зависимости и внешние CDN не нужны. Для интерфейса требуется JavaScript. При открытии index.html через file:// загрузка текстового файла может блокироваться браузером.

Разбор проверен на текущем исходнике: 5 категорий, 38 тем, 1012 пронумерованных блоков. Форумные даты, авторы, реакции, кнопки, названия вложений и дубли тем не отображаются. Длительности наказаний, расписания и примеры никнеймов в правилах сохраняются. Явные объявления «Стало» применяются последовательно; неполные формулировки не дописываются. Недоступные карты не восстанавливаются.

Поиск: слова (все слова запроса), номера и подпункты; регистр не важен, е/ё равнозначны. Область — текущая тема или все темы. Подразделы фильтруются отдельно. Ctrl+K — поиск, Esc — сброс.

Для обновления материалов редактируйте исходный TXT, сохраняя заголовки и структуру тем. После существенного изменения структуры проверьте результат разбора. Исходник хранится без изменений; очистка выполняется при отображении. Актуальность относительно официального форума независимо не проверялась.
