# NOVARP — справочник правил NOVA RP

Автономный одностраничный справочник правил проекта NOVA RP (GTA 5 RP): весь текст хранится в `index.html`, чтение работает без интернета, сервера и JavaScript.

## Поиск

Поисковый движок — `search.js`. Подключение (одна строка в `index.html` перед `</body>`):

```html
<script src="search.js" defer></script>
```

Возможности:

- поиск по словам: несколько слов — все должны встретиться в пункте; регистр не важен, «е» и «ё» равнозначны;
- поиск по номеру пункта: `4.15`, `2.13`, `п. 4.15` — открывает пункт и его подпункты (например `4.15.1`);
- подсветка совпадений, счётчики в оглавлении, скрытие разделов без совпадений;
- кнопка «Показать раздел целиком» внутри отфильтрованного раздела;
- горячие клавиши: `Ctrl+K` — поиск, `/` — поиск, `Esc` — сброс;
- ссылка на результат: `index.html?q=ограбление`.

## Как править правила

Раздел — это `<article id="sN">` с заголовком `<h2>` и текстом в `<div class="body">` (обычный текст, абзацы разделяются пустой строкой). Поиск индексирует пункты автоматически по нумерации в начале абзаца (`1.1`, `4.15`, `2.13.1`) — ничего настраивать не нужно.
